# About

SEC-bench Pro expands the SEC-bench benchmark family toward harder, project-specific security evaluations. The current leaderboard release reports `source_files` results across Chromium V8, Firefox SpiderMonkey, and Linux, with an overall view for comparing complete runs across projects.

### Acknowledgement

SEC-bench Pro inherits the core SEC-bench goal: evaluating whether language-model agents can solve authentic software security problems under reproducible conditions.
